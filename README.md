# Unstuck

A no-cost, static starter website for everyday technology troubleshooting. The first guides cover Wi-Fi connectivity in Windows and common Chrome page-loading errors.

## Run locally

Open `index.html` in a browser. The site has no build step, dependencies, account, analytics, or backend.

## Publish with GitHub Pages

1. Create a GitHub repository you control and add the contents of this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
4. GitHub will show the public URL when the first deployment finishes.

This project is not connected to a repository or hosting account yet, so it has not been published. GitHub Pages can host a static site at no charge under its current plan and usage limits; public availability and terms are controlled by GitHub.

## Scope and trust

- Google does not publish a measure or ranking of which search answers leave users dissatisfied. The initial topics are practical support questions, not a claimed Google ranking or satisfaction study.
- The guides are concise summaries linked to official Google and Microsoft help pages. Product interfaces can change; consult the linked page for current, device-specific instructions.
- “This helped” and “Still stuck” votes are stored only in that visitor's browser using `localStorage`. They are not transmitted, counted across visitors, or visible to the site owner.
- The search box filters the starter guides. When no guide matches, it opens a Google search for the visitor's exact query.
- No personal information should be entered; this site has no secure support inbox or account system.
