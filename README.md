# Unstuck

A no-cost, static starter website with practical guides for everyday technology issues. Current topics include Windows Wi-Fi, Chrome page-loading errors, and bank-account holds linked to cybercrime complaints in India.

## Run locally

Open `index.html` in a browser. The site has no build step, dependencies, account, analytics, or backend.

## Publish with GitHub Pages

The site is configured to publish from the `main` branch at the repository root.

- Website: <https://iamkuldeepdubey.github.io/Unstuck/>
- Source: <https://github.com/IamKuldeepDubey/Unstuck>

GitHub Pages hosting uses the free `github.io` address and current plan/usage limits. A custom domain is optional and is not configured.

## Help people find the India bank-hold guide

The guide has its own shareable URL: <https://iamkuldeepdubey.github.io/Unstuck/bank-account-lien-india.html>. The root `sitemap.xml` lists that page and the home page.

To request Google indexing (not a guarantee):

1. In [Google Search Console](https://search.google.com/search-console), add the URL-prefix property `https://iamkuldeepdubey.github.io/Unstuck/`.
2. Verify ownership using a method Search Console offers. If it provides an HTML verification file, place that file at this repository's root and commit it before verifying.
3. Submit `https://iamkuldeepdubey.github.io/Unstuck/sitemap.xml` in the property's **Sitemaps** section.
4. Use **URL Inspection** on the bank-hold guide and choose **Request indexing**.

Google says crawling can take days to weeks and that a request does not guarantee inclusion in search results. Search Console requires access to a Google account that can verify this site.

## Scope and trust

- Google does not publish a measure or ranking of which search answers leave users dissatisfied. The initial topics are practical support questions, not a claimed Google ranking or satisfaction study.
- The guides are concise summaries linked to official Google, Microsoft, I4C, NCRP, and RBI information. Product interfaces and procedures can change; consult the linked source for current details.
- The India bank-account hold guide uses official I4C, National Cyber Crime Reporting Portal, and RBI complaint resources. It is general information, not legal advice; it does not promise release or a fixed timeline.
- “This helped” and “Still stuck” votes are stored only in that visitor's browser using `localStorage`. They are not transmitted, counted across visitors, or visible to the site owner.
- The search box filters the starter guides. When no guide matches, it opens a Google search for the visitor's exact query.
- No personal information should be entered; this site has no secure support inbox or account system.
