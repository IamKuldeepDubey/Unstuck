Wi-Fi · WindowsAbout 5 minutes

Wi-Fi is connected, but there’s no internet

First check whether the problem affects just this PC or every device on the network.

  1. On another device using the same Wi-Fi, try opening a website. If that also fails, restart the modem and router; wait for them to reconnect.
  2. On your PC, confirm Wi-Fi is on and Airplane mode is off.
  3. If only this PC is affected, forget the network in Settings → Network & internet → Wi-Fi → Manage known networks, then reconnect with the password.
  4. On Windows 11, run the Network and Internet troubleshooter in the Get Help app.

Restarting the router briefly disconnects everyone using that Wi-Fi. On a work or school device, contact your administrator before changing network settings.

Verified against Microsoft’s Windows Wi-Fi guide.

Chrome · BrowserAbout 3 minutes

A website won’t load in Chrome

The error code is a clue. Check whether it’s one website or every website before changing settings.

  1. Try another website. If none load, check your internet connection first.
  2. Reload the page. If it still fails, note the exact error (for example, ERR_NAME_NOT_RESOLVED or ERR_CONNECTION_TIMED_OUT).
  3. If only one site fails, try again later or contact that site’s owner; the problem may be on their side.
  4. If Chrome says “Connect to network,” sign in to the Wi-Fi network’s welcome page. On a work device, ask your administrator about certificate or proxy errors.

Don’t bypass a certificate warning or install a certificate from an untrusted source. On managed devices, ask your organization’s support team.

Verified against Google Chrome’s common error guide and its connection troubleshooting steps.
